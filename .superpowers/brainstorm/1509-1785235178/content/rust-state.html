After Comparison: Switch Between Total / Diff

Both parquet files are available. A toggle in toolbar lets user switch without re-comparing:

shows differences only
⇄
TOGGLE ON
compare_total.parquet
shows all rows
Toggle is instant — both files already on disk, just load the other one.
